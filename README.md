# Red-Zone
 Game developed for university classes, to ilustrate the concepts of semaphores and threads is operational systems

## Unity project (recovered)

The original project files were lost. `Assets/`, `Packages/` and `ProjectSettings/` were rebuilt
from the Windows build in `Comp3/` (Unity 2019.2.6f1, Mono) with AssetRipper, so the 5 game scripts
are the real decompiled code. The project was then upgraded to Unity 6 (6000.5.1f1): the loose UI
DLLs were replaced by the `com.unity.ugui` package and every scene reference was remapped to it.

The game was designed for a 1024x768 (4:3) window.
